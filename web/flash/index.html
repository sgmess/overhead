Overhead

Live ADS-B radar · web flasher · __VERSION__

Install

M5Stack Tab5ESP32-P4, 720×1280

This browser can't flash boards. Use Chrome or Edge on a computer: Web Serial isn't in Safari, Firefox or on phones.

Flashing needs the page over HTTPS.

Choose "Erase device" when it asks: a first install needs the whole flash written. It takes a minute or two.

Before you start

  1. Connect the Tab5's USB-C port to the computer with a data cable, and switch it on.
  2. Press Connect and install and pick the port named USB JTAG/serial debug unit. If none appears, try another cable or port.

The Tab5's WiFi runs on its ESP32-C6 co-processor, and this firmware expects esp_hosted 2.12 on it. With older C6 firmware the radar restarts when WiFi starts; update the C6 first.

After installing

  1. Keep this page open: once the Tab5 has restarted, the installer offers Connect to Wi-Fi. Pick your network, enter its password, and it joins straight away.
  2. Then Visit device opens its settings, where you set the radar's centre and the rest. Later they're at http://overhead.local, and updates install from there too, under Firmware, with no cable.

Skipped that step, or the Tab5 is away from the computer? It opens its own WiFi network, Overhead-XXXX, with a QR code on screen that joins it; the setup page then opens on your phone by itself (or browse to 192.168.4.1).
